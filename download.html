    Antes de empezar

    Descarga el instalador para Windows, macOS o Linux. Dvarc puede descargar y administrar Java por ti.

    Después de instalar

    Abre el launcher, inicia sesión o elige jugar offline y entra en Nueva instancia para ver las versiones disponibles.

    Juega sin preparar todo a mano

    El launcher instala automáticamente los mods, resource packs y shaders de cada versión.

    Si GitHub limita la consulta o no hay releases, puedes revisar todas las releases del repositorio.
